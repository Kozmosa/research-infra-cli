## 3. arcli 工作流指南

### 3.1 数据管理

注册数据资产（在修改原始数据前执行）：

```bash
arcli data register ./data/raw --name my-dataset --desc "Dataset description"
```

### 3.2 实验生命周期

创建实验（强制声明数据、命令、环境）：

```bash
arcli exp new --data my-dataset --cmd "python train.py --epochs 10" --label baseline
```

执行实验：

```bash
arcli exp run run-001-{TIMESTAMP}_baseline
```

记录指标：

```bash
arcli exp metric run-001-{TIMESTAMP}_baseline --step 1 --json '{"loss": 0.5, "acc": 0.92}'
```

完成实验并同步：

```bash
arcli db sync --mode export
```

## 5. 双轨持久化

| 存储 | 格式 | 用途 | 版本控制 |
|------|------|------|---------|
| SQLite | `.research/research.db` | 运行时缓存、高效查询 | **忽略** |
| JSON | `{EXP_DIR}/experiment.json` | 事实来源、可复现 | **纳入** |

同步命令：

```bash
# SQLite -> JSON（实验后执行）
arcli db sync --mode export

# JSON -> SQLite（拉取新实验后执行）
arcli db sync --mode import

# 自动比较时间戳合并（pre-commit 钩子推荐）
arcli db sync --mode auto
```

## 6. 规范约束

1. **工作区净空**: `exp new` 前须 `git status --porcelain` 为空，确保实验绑定 clean commit
2. **数据只读**: `data/raw/` 在实验过程中不得被修改
3. **实验即契约**: 实验创建时声明的数据、命令、环境不可事后篡改（可通过 `exp param` 补录参数）
4. **JSON 为真理**: 所有实验的可复现信息以 `experiment.json` 为准
