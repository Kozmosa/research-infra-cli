工作流

01 注册数据

将数据集注册为资产，计算 SHA256 校验和。

arcli data register ./data/raw --name my-dataset
02 创建实验

声明数据、命令、环境，生成唯一实验 ID。

arcli exp new --data my-dataset --cmd "python train.py"
03 执行实验

运行命令，自动捕获 stdout/stderr 到日志。

arcli exp run run-001-{TIMESTAMP}
04 记录指标

按 step 记录结构化指标。

arcli exp metric run-001-{TIMESTAMP} --step 1 --json '{"loss":0.5}'
05 同步归档

导出 SQLite 到 JSON，纳入版本控制。

arcli db sync --mode export
git add {EXPERIMENTS_DIR}/*/experiment.json

双轨持久化

SQLite

.research/research.db

运行时缓存。支持高效查询、原子操作、并发写入。

JSON

{EXPERIMENTS_DIR}/*/experiment.json

版本控制事实来源。人类和 Agent 最终只需信任 JSON。

同步流程

┌─────────────┐     export      ┌─────────────────┐
│  SQLite     │ ───────────────→│ experiment.json │
│ research.db │                 │ (版本控制事实源) │
│  (运行时缓存) │ ←───────────────│                 │
└─────────────┘     import      └─────────────────┘
        ↑                              ↑
        │    db sync --mode auto       │
        │    按 updated_at 比较合并     │
        └──────────────────────────────┘

使用场景

  • 实验后: db sync --mode export 将 SQLite 写入 JSON
  • 拉取后: db sync --mode import 将 JSON 读入 SQLite
  • pre-commit: db sync --mode auto 自动比较合并
